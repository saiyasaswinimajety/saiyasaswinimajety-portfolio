## Architecture & Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: TailwindCSS v4 + Vanilla CSS Design Tokens
- **Animations**: Framer Motion & Interactive Canvas
- **Typography**: Google Fonts (Montserrat & Lato)
- **Quality Gates**: ESLint 9, Prettier, TypeScript Strict Mode, Husky Pre-Commit Validation
